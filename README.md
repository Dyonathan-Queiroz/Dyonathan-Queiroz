## 📌 Sistemas em produção

### [🚚 Sistema Logístico Gavião](https://github.com/Dyonathan-Queiroz/Sistema-de-logistica)

Sistema web de gestão logística em produção no Supermercado Gavião: controle de frota, entregas, desempenho de motoristas e sincronização automática com o ERP via Oracle.

**Destaques técnicos:**
- Back-end em **FastAPI** com **MySQL**, **SQLAlchemy** e migrations com **Alembic**
- Deploy com **Docker Compose**
- Agente de sincronização com o banco **Oracle** do ERP
- Segurança: senhas com **bcrypt**, sessão assinada com **HMAC-SHA256**, rate limiting no login e headers de segurança (CSP)
- PWA instalável no celular dos entregadores
